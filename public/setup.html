First Vigil

Set the word and the key. The scriptorium opens for the first time.
Step 1

The Word (Password)

Choose a password. It will be hashed and displayed for you to set as an environment variable in Railway.

Copy this to Railway env var DISMAS_PASSWORD_HASH:
Step 2

The Second Key (MFA)

Generate a TOTP secret and scan the QR code with Google Authenticator or similar.

Scan with Google Authenticator:
Copy this to Railway env var DISMAS_TOTP_SECRET:
Step 3

Set Environment Variables in Railway

Go to Railway > your service > Variables and add these:

Required Env Vars

DISMAS_PASSWORD_HASH=(from step 1)
DISMAS_TOTP_SECRET=(from step 2)
DISMAS_SESSION_SECRET=any-random-string
DATA_DIR=/data

Also add a Railway Volume mounted at /data for persistent storage.

After setting env vars, redeploy. Then visit the URL again - you'll get the login page instead of setup.
